## 🧩 Project Overview  
**SIMAA UGM (Sistem Manajemen Acara UGM)** is a database project developed to streamline the management of campus events at **Universitas Gadjah Mada**.  
The system provides a centralized platform for managing organizers, students, events, venues, and registrations — replacing fragmented workflows that often rely on spreadsheets or manual forms.  

This first version focuses on the **database design**, ensuring data consistency, supporting CRUD operations, and serving as a foundation for future extensions such as feedback and analytics.

---

## 🎯 Objectives  
- Design a **structured relational database** for student, organizer, event, registration, and venue management.  
- Support **basic CRUD operations** to facilitate event creation and participant registration.  
- Maintain **data integrity** through well-defined relationships and constraints.  
- Establish a **scalable schema** for upcoming features like feedback and reporting.
